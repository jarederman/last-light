## Project work

The rainy-night station background (`assets/scenes/station-night.webp`), Echo’s walk sheet (`assets/characters/echo-night.png`) and Mara’s sprite (`assets/characters/mara-night.png`) were generated for this project with the built-in OpenAI image-generation tool. They are project-generated artwork, not downloaded CC0 packs. The characters use the environment as their palette and style reference. Images were resized, transparency cleaned and frames aligned for runtime; no scene artwork is procedurally drawn. See `assets/art-direction.md` for prompts and packing details.

The prior Kenney/Fleurman/Airos visual assets have been replaced and are no longer shipped. The UI, collision layout and signal waveform diagrams are project code. The small SVG favicon is original project UI artwork.

Source and license notices are in `assets/licenses/`. The ambient recordings are integrated into the game and are not offered as standalone stock audio. Original MP3 downloads are not included.
