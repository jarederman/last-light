## Project work

The station layout, lighting, game UI and signal waveform diagrams were assembled or implemented for Last Light. The small SVG favicon is original project UI artwork.

The packaged originals' license notices and supplemental source notices are in `assets/licenses/`. CC0 reference is https://creativecommons.org/publicdomain/zero/1.0/.
